# SignalForge Agent

SignalForge Agent is an AI-powered operations framework for startup and VC lead intelligence. It unifies lead enrichment, deduplication, outreach planning, mailbox reply triage, company briefings, qualification, follow-up automation, conversion tracking, and Feishu-based workflow orchestration into one reliable operating system for modern startup programs.

## What it includes

- End-to-end lead operations from intake to conversion
- High-confidence company and contact enrichment
- Controlled outreach and follow-up workflows
- Mailbox reply classification with instant company briefings
- Startup qualification and program-manager routing
- Feishu bot commands, proactive alerts, and confirmation controls
- Privacy-safe handoff and deployment guidance

## Privacy

This repository is intentionally generic. It contains no customer records, mailbox addresses, app identifiers, OAuth tokens, Base links, internal URLs, user IDs, proxy settings, or message bodies.

Keep deployment credentials in the destination environment's secret manager, never in Skill files or Markdown.
